# Тестирование

## апуск тестов

```bash
# се тесты
pytest

# С покрытием
pytest --cov=. --cov-report=html

# онкретный файл
pytest tests/test_all.py -v
```

## Структура тестов

```
tests/
└── test_all.py    # сновные тесты модулей
```

## учное тестирование

осле запуска бота (`python bot.py`) проверить:

1. `/start` — корректный онбординг
2. тправить фото еды — распознавание и подсчёт 
3. `/today` — итог дня
4. `/report` — генерация Excel-файла
5. `/settings` — изменение настроек напоминаний
